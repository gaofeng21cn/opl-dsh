选择模型来源与执行引擎，保存为可复用的执行组合，并在官方对话中使用。

入口：**设置 → 执行与组合**；日常切换使用输入框的模型与执行引擎菜单。模型与凭据仍由模型来源负责，本插件保存组合、外部会话关联和执行记录。

独立配置的原生 Provider 如果没有官配或自动外部 Harness 推荐，且模型在官方目录中可用，会自动获得只读 DSH fallback，供官方对话直接选择。OPL Gateway、OFM 和外部 CLI 账号专属来源不使用此 fallback。它只保存模型引用与 DSH 绑定，不改变模型连接、协议、凭据的 owner，也不会自动换用外部 Harness；已有默认组合和用户停用选择保持优先。

Codex、Claude Code 等执行程序需要在本机就绪。可用范围以组合页面的实际状态为准。关闭本插件后，外部执行适配和组合入口停止加载，历史数据保留；依赖它的 OPL 跨引擎协作暂停。DSH 的原生会话、角色和权限由官方继续管理。

配合 **OPL 跨引擎协作**，可给官方角色绑定执行组合并接入官方团队通信。OPL Gateway 账号由 **OPL DSH 基础增强** 管理，其他模型来源由各自插件管理。

MiniMax 官方 mcode 集成默认开启，可在本页停用。停用会移除对应 Provider、模型与组合投影及模型供应商页的账号卡片，并拒绝新的 mcode 轮次；已有组合、官方凭据和历史会话保留，其他目录保存不会删除隐藏行。重新启用可恢复；在途官方网页登录会收到协作取消。
