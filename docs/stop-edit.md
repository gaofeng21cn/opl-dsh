# 编辑消息

原生 DSH 对话的“编辑消息”在原对话内替换重发，首条消息也不创建分支。每条可编辑的用户消息在悬停或键盘聚焦时，右下角显示与“复制”并列的编辑图标；点击该图标即选择这条消息，原文回填到官方输入框。选择和修改草稿时，聊天记录保持原样。点击普通发送按钮后，所选消息及其后续回复从当前聊天视图和下一次模型输入中移除，修改后的消息在同一个会话中发送。

输入栏右侧的关闭图标可取消编辑，保留原聊天记录并恢复选择前的草稿。切换对话和新建对话不会继承另一条对话的编辑目标。重新加载后，原会话的编辑目标与官方草稿一起恢复。

编辑需要会话已经停止且没有待发送消息。带附件的消息、已经压缩或替换的消息暂不提供编辑。原生子任务和受协作台账管理的任务不使用该入口。外部 Harness 暂不提供原对话内编辑，仍可使用官方 Fork 菜单创建分支；套件不把分支当作替换重发。旧版生成的编辑分支及其日志保留可读。

发送使用官方空闲维护机制与公开会话表面替换接口，输入校验完成后再提交替换并刷新持久记录；原始事件仍保留用于审计，不从磁盘删除会话日志。只有带 OPL 编辑标记且对应新消息已落入日志的范围会从聊天视图隐藏，普通压缩不隐藏用户原聊天记录。文件内容始终保持原样，不撤销已经执行的工具。

若选择后对话发生变化，发送会要求重新选择。传输或持久化结果不确定时不会自动再次替换，也不会把它描述为未生效；原始记录保留，未确认的替换阻断后续模型请求。

如果替换已经写入，但模型准备失败或取消发生在新消息落盘之前，入口显示“重试未确认的编辑”。该操作使用持久记录中的原请求与原文本重新提交缺失的消息，不再次替换历史、不自动重派。读取状态或重启不会发送请求；内容或身份不符仍拒绝恢复。
