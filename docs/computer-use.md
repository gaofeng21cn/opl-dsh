# KimiCU WinCU

DSH 检查 Windows x64 主机是否达到 Windows 10 build 18362（1903）或更高版本，并提供官方 Kimi Code 插件安装入口：

`/plugins install https://cdn.kimi.com/kimi-computer-use-windows/latest/kimi-cu-win-plugin.zip`

当前公开资料没有提供插件的可验证安装路径，也没有可由 DSH 启动的稳定 stdio/MCP 命令、JSON-RPC 协议或工具清单。因此 DSH 会明确报告安装状态无法自动确认，只提供官方安装说明；不声明工具可用，不下载或执行未知程序，也不读取凭据。computer-use 调用必须通过显式权限门禁；协议公开并完成 Windows 实机验证前，状态保持不可用。
