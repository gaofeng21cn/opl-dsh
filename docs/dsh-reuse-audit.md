# 官方 DSH 能力复用检查

检查日期：2026-10-30。对照官方 `dsh-v0.2.1-rc.5` 的源码、公开包接口与双平台桌面 feed，沿 OPL Suite 的 Host/Client 挂载、安装器和实际调用者检查职责边界。

目标是撤除已不使用的华为云接入，并把官方已有能力交回原负责人。本次不新增页面、导航、配置存储或 Agent 循环。

## 保留的兼容边界

官方 `ProviderEditor.layoutOf` 当前仍只识别 `llm-deepseek` 与 `llm-pi-ai`。Bamboo/TypeSafe 使用独立决策协议，无法直接交给 pi-ai 流式聊天适配器。因此保留现有 namespace 的公开 Schema 扩展、精确 Jev 模型发现和固定凭据目标；没有另建设置表单。官方支持插件自行声明编辑布局后，可撤去这处兼容实现。

OPL 的外部执行器需要持久会话、实时工具展示、人工审批与任务续作；官方一次性 subagent 提供方返回最终答案，且配置与生命周期不同。直接替换会丢失当前用户任务，故保留转换层，执行循环继续使用官方 CLI/SDK。

官方 `ui-model-selection` 公开了模型目录服务，但其菜单组件未从公开 Client 入口导出，选择身份也只有 provider/model。OPL 需要区分同一模型的多个 Harness 组合，因此保留组合菜单，复用官方 MenuSurface、Slot 与模型选择投影；不把它描述为原生选择器组件。Gateway 的六组账户与精确渠道选择也保留在原生模型页中的既有投影。

## 华为云退役与数据

增强包不再注册华为云供应商、模型、自动组合、凭据目标或请求转发，也不再打包其独立桥接程序。移除只针对实现与入口，不读取或删除现存系统 Key、旧配置和会话；原来保存的组合仍按缺失模型处理。OFM 的 ZCode/Kimi 接入与共享协议继续保留。

当前结论以源码调用链及验收结果为范围。官方持续更新时，应重新检查上述接口和兼容边界；发布状态以对应 Release 的双平台资格 JSON 为准。
