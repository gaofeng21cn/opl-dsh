# Todo 状态展示

输入栏的 Todo 面板读取会话实际记录的待办清单，不从回答正文或草稿中提取清单。模型未调用 `todo_write` 时不显示面板；原生 DSH 新回合开始后，官方投影会清空上一回合的清单。

记录为 `completed` 的项目显示已完成，`pending` 显示待处理。`in_progress` 在会话运行时显示“进行中”；会话停止后静态显示“未完成”，不继续旋转，也不自动改成已完成。记录状态表示模型写入的清单状态。

折叠状态只显示标题与各状态数量。会话活动、未知状态和说明放在标题悬停提示中；只有真实运行中的子会话保留一行简短提示。子会话运行或结束不会改变任何待办项目，不按项目文字推测对应关系。

点击面板标题可展开或折叠；标题按钮支持键盘操作。长项目文本保留完整内容，并使用单行省略显示。清单和历史工具记录保持只读，面板不会启动、停止或恢复任务。

面板通过官方 Client 的 `conversation.input.dock` 扩展加载；停用该扩展后恢复官方面板，不修改官方应用资源。
