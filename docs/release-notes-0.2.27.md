- 隔离验收使用本地模型 fixture，不代表真实华为云请求、第三方账号登录或所有 Harness 组合已验收。
- 华为云密钥存储目前沿用 Windows 凭据管理器；macOS 不提供该密钥写入。OFM 的账号、模型、路由与更新由原版插件维护。

- 直接打开官方桌面不会启动外部 OPL 更新器；OPL 维护入口或启用自动启动的 Codex Skill 执行增强更新，官方桌面继续按 DeepSeek 原生机制升级。
