# 上下文预算观测

在“设置 → 上下文预算”开启“显示上下文预算”后，对话输入栏会出现预算入口。默认关闭，显示偏好保存在本机；关闭时不读取预算。面板仅显示当前可读取的模型信息和 token 数值，未提供的执行方式、压缩阈值、保留尾部及其他数值不占用界面。

悬停数值行可查看该项来源与含义，悬停面板标题可查看观测时间和完整说明。模型声明的窗口和默认输出额度来自适配器元数据；最近请求输出上限来自已记录的请求头，上下文占用来自官方会话投影。容量声明不保证服务端实际容量，投影总占用是估算，用量锚定占用不是精确即时值。

打开面板或点击刷新会重新读取，模型选择和会话运行状态变化也会触发读取；占用数值不逐帧刷新。点击面板外部或按 Esc 收起，面板内点击不收起。读取期间清除旧数字并显示读取状态；切换会话或重连后，旧结果不会进入新会话。读取失败提供简短提示和重试入口。

面板不发送模型请求、不调整参数或压缩策略，不读取外部 Harness 私有配置，也不将 ACP 模型目录当作实际预算。
