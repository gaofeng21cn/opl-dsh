本版统一华为云 MaaS 的凭据管理，macOS 与 Windows 都在现有模型供应商表单中保存、修改和删除 API Key。

### 变更

- 华为云凭据完全复用官方凭据服务，移除仅支持 Windows 的读写限制。来源优先级、只读环境凭据、保存事件和文件保护沿用官方机制，不增加独立设置页、卡片或操作流程。
- 旧 Windows Key 首次升级时迁入统一存储，已有统一凭据优先。旧条目保留供旧版本恢复，迁移完成后不再作为正常执行的回退来源；手动删除的供应商和 Key 不自动恢复。
- ZCode 通过现有私有进程通道按请求读取 Host 的华为凭据，更换和删除 Key 能被后续请求即时读取。密钥不进入启动环境、参数或 ZCode 配置；模型、Harness 和执行组合的职责保持原有设计。
- 复查相关页面、模型可用状态和说明，移除残留的 Windows 专属凭据描述。

### 验证

- Host/Client 类型、RPC、模块边界、格式、构建及自动测试通过发布门禁。
- 未修改的官方 macOS arm64、Windows x64 桌面在隔离 profile 中验收同一增强包；两端均通过原生表单实际保存、更换、删除 Key，并回读官方存储。模型与工具流、OFM 原页面、重启恢复及签名完整性继续通过验收。
- 自动测试覆盖旧凭据迁移、已有来源优先、删除后不恢复、迁移失败保留、ZCode 按请求读取及私有通道拒绝未声明方法。
- 源提交为 `{{SOURCE_COMMIT}}`；双平台资格证据、联合清单与公开资产摘要随 Release 提供。

### 已知限制

- 默认统一存储由官方 `dsh-credentials-local` 管理，并非操作系统加密钥匙串；启动环境提供的 Key 优先且只读。
- 隔离验收使用本地模型 fixture，不代表真实华为云模型请求、第三方账号登录或所有 Harness 组合已验收。ZCode 组合仍要求明确授权的完整访问。
- 直接打开官方桌面不会启动外部 OPL 更新器；OPL 维护入口或启用自动启动的 Codex Skill 执行增强更新，官方桌面继续按 DeepSeek 原生机制升级。

### 升级

退出 DeepSeek Harness 后运行最新安装器，或使用 OPL 维护启动入口。升级保留账号、会话、执行组合和用户修改；旧 Windows Key 自动迁移，无需重新填写。迁移失败保留原凭据并提示重试，不替换运行中的 profile。
