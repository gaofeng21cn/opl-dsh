# 对话中的文件交付

增强包在普通 DSH 对话中为回复里的 `deliver-assets` 文件标记添加可点击条目。条目保留文件名和绝对路径，使用官方文件打开入口；打开失败仍由对话界面反馈。条目不会自动读取文件或执行命令。

只转换闭合、位于代码块与行内代码之外、完全由本地 `file` 项组成的标记。支持 Windows 盘符、UNC 与 POSIX 绝对路径，以及单层 Markdown 反斜杠或尖括号实体转义。远程 URL、相对路径、其他媒体类型、残缺标记和混入正文的块保持原文，不影响后续有效交付。Windows 大小写与两种路径分隔符按同一文件去重，显示第一次提供的写法。

查看历史记录会重新生成条目，不发送模型请求或执行历史工具。重试开始时旧条目隐藏，下一条回复提供新的文件列表；没有文件的回复不会保留旧文件入口。

这项增强通过官方公开 Conversation 扩展添加正文条目，不放入折叠的执行过程区。原始回复和复制内容保留，官方 Markdown 正文里的原始标记仍可能显示；当前没有替换正文的公共预处理接口。Windows 隔离官方 Desktop 验收覆盖历史条目可见、点击后预览文件、缺失文件提示与页面重载；用户当前安装需单独更新才能使用。
