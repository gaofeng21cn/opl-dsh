本版接入原版 Our Free Model，整理模型来源与执行设置，减少冗余入口。官方桌面按发布时两个平台的实际 feed 配对；开发 API 依赖继续使用 `0.2.1-alpha.2`。

### 变更

- 修正英文设置导航的长名称，使账户入口完整显示。v0.2.22 的未公开候选保留为验收记录，本版包含该候选的全部功能与本次修正。

- 通过官方插件管理器安装原版 Our Free Model，保留免费模型、EAC、13 个账号渠道、聚合来源、虚拟路由、用量和更新能力。OPL 从官方模型注册表生成 DSH 执行组合，不复制上游路由或另建模型插件。
- 重装或升级 OPL 时保留已有 OFM 来源、停用状态及自行更新后的完整包文件；缺失的已声明插件由官方管理器修复。
- 华为云 MaaS 的 GLM-5.2 与 API Key 配置移入“模型供应商”页面，移除独立设置入口，继续使用原凭据存储与官方 ZCode 组合。
- 设置导航按账户与来源、执行与组合、协作与行为、插件管理排列；“运行配置”改为“执行组合”，“Harness”改为“执行引擎”，“Auto Review（工具审批）”改为“工具审批”。原版 OFM 入口统一显示为“OFM 模型服务”，页面与更新仍由上游维护。
- 开发约定明确：吸收新能力先检查并复用现有 UI 与交互，非必要不新增页面、导航项、重复配置或操作流程；新增交互须说明现有入口无法承载的用户需求。

### 验证

- 发布门禁覆盖 Host/Client 类型、RPC、模块边界、格式、构建与自动测试。
- macOS arm64 与 Windows x64 使用同一增强包字节，验收未修改的官方桌面；覆盖设置导航、华为云供应商卡片、OFM 原页面、模型流、官方工具、外部 Harness 和重启恢复。
- 联合清单、两平台资格证据、公开资产与摘要由发布流程逐项核对；源提交为 `{{SOURCE_COMMIT}}`，验收记录随 Release 提供。

### 已知限制

- 隔离验收使用本地模型 fixture，不代表逐个第三方账号登录、真实 Gateway、华为云请求或所有 Harness 组合已验收。
- 华为云 Key 存储沿用 Windows 凭据管理器；此接入不提供 macOS 凭据存储。Key 和官方 ZCode 未就绪时，组合会显示不可用。
- OFM 的账号、模型可用性、路由与更新行为由原版插件及其服务提供方维护；OPL 保留其原始功能与配置，不承诺第三方渠道持续可用。
- 直接打开官方桌面不会启动外部 OPL 更新器；OPL 维护入口或已启用自动启动的 Codex Skill 执行增强包更新，官方桌面继续由 DeepSeek 原生机制升级。

### 升级

退出 DeepSeek Harness 后运行最新安装器，或使用 OPL 维护启动入口。安装器和更新器校验联合清单与资产摘要，保留账号、会话、执行组合及用户修改；失败保留当前安装，不替换运行中的 profile。
