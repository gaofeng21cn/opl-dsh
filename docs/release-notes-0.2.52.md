官方 DeepSeek Harness：`{{OFFICIAL_VERSION}}` · OPL 增强：`{{VERSION}}`

本版撤除已停用的华为云接入，清理与官方能力重复的遗留实现，并跟进官方 DSH 0.2.1-rc.5。

### 变更

- 移除华为云 MaaS 的 GLM、Kimi 和 DeepSeek 模型入口、自动组合、专属凭据管理与请求转发；现有用户配置、系统凭据和历史会话保留，旧组合显示不可用。
- ZCode 与 Kimi Code 继续支持已适配的 OFM 免费模型，使用 OFM 自己的连接与凭据。
- 冷会话模型选择复用官方持久投影接口，重启后读取历史模型不再依赖 OPL 的关联记录或 profile 默认值，也不创建或激活 Agent。
- 删除旧上下文预算服务及未使用的界面，token 用量与上下文占用继续使用官方 DSH 统计；移除重复注册的原生进度保护。
- 系统核对桌面、插件安装、模型、会话、工具、权限、协作和设置的维护边界，保留承担现有用户任务的转换层。检查结论见仓库「官方能力复用检查」。
- 所有 DSH 开发依赖统一升级到 0.2.1-rc.5；官方桌面仍通过官方 feed 下载、校验与更新。

### 验证

- Host/Client 类型检查、RPC、模块边界、格式、构建与自动测试：通过
- macOS arm64 与 Windows x64 未修改官方桌面隔离验收：通过
- 两平台验收同一增强包字节，覆盖 Client 设置、模型流、官方工具与重启恢复；源提交为 `{{SOURCE_COMMIT}}`
- 联合清单与验收记录随 Release 提供；发布后逐一回读公开资产摘要

### 已知限制

- 官方桌面 0.2.1-rc.5 仍属于上游候选阶段；开发 API 依赖与实际桌面版本分别记录。
- 本地模型 fixture 验证协议、工具和持久化链路；外部服务可用性与全部 Harness 组合需要对应账号和运行环境。
- Windows Git Bash 验收使用显式授权的完整访问权限，受限 token 下的外部程序限制仍保留。
- 直接打开官方桌面不会运行外部 OPL 更新器。

### 升级

退出 DeepSeek Harness 后运行最新安装器，或使用 OPL 维护启动入口。更新失败保留当前安装；已有配置、凭据和会话保留。
