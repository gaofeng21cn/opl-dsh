官方 DeepSeek Harness：`{{OFFICIAL_VERSION}}` · OPL 增强：`{{VERSION}}`

本版让华为云 MaaS 完整复用原生模型提供商交互，移除上一版保留的专属卡片。未公开的 v0.2.24 候选保留，本版包含完整适配及模型目录修正。官方桌面按发布时两个平台的实际 feed 配对；开发 API 依赖继续使用 `0.2.1-alpha.2`。

### 变更

- 在“模型供应商 → 添加模型提供商”的内置目录中选择“华为云 MaaS”，使用同一套 API 密钥输入、保存、编辑及删除确认流程；不再提供独立页面、页尾卡片或专属凭据表单。
- 添加提供商后注册 GLM-5.2 与自动 ZCode 组合，删除后撤销自动模型与组合投影；已有用户组合保留为不可用引用，不重新注册提供商，也不读取或探测其 Key。模型目录只检查配置与凭据存在性，Key 仅在实际请求中读取；继续由官方 ZCode 执行组合处理模型请求，保持模型来源、执行引擎与执行组合的职责。
- Windows API Key 继续使用原有系统凭据管理器位置。首次升级只读取旧 Key 的存在性以恢复提供商配置，不复制或重写 Key；用户删除提供商后，重启不会再次自动添加。
- 开发约定明确：把专属组件移动到已有页面不等于复用交互。已有添加、编辑与删除流程能承载时，优先复用，不另加专属卡片或弹窗。
- 原版 Our Free Model 的账号、模型、路由、管理页面和自行更新能力保持完整。

### 验证

- 发布门禁覆盖 Host/Client 类型、RPC、模块边界、格式、构建与自动测试。
- macOS arm64 与 Windows x64 使用同一增强包字节，验收未修改的官方桌面；覆盖原生提供商添加、编辑、删除与目录恢复、密码框不回显、设置导航、OFM 原页面、模型流、官方工具、外部 Harness 和重启恢复。
- Windows 临时 runner 通过原生 UI 保存及删除合成测试 Key；macOS 验证不支持的凭据输入锁定，不写系统凭据。
- 联合清单、两平台资格证据、公开资产与摘要由发布流程逐项核对；源提交为 `{{SOURCE_COMMIT}}`，验收记录随 Release 提供。

### 已知限制

- 隔离验收使用本地模型 fixture，不代表真实华为云请求、第三方账号登录或所有 Harness 组合已验收。
- 华为云 Key 存储沿用 Windows 凭据管理器；此接入不提供 macOS 凭据存储。Key 和官方 ZCode 未就绪时，组合显示不可用。
- OFM 的账号、模型可用性、路由与更新由原版插件及其服务提供方维护。
- 直接打开官方桌面不会启动外部 OPL 更新器；OPL 维护入口或已启用自动启动的 Codex Skill 执行增强包更新，官方桌面继续由 DeepSeek 原生机制升级。

### 升级

退出 DeepSeek Harness 后运行最新安装器，或使用 OPL 维护启动入口。安装器和更新器校验联合清单与资产摘要，保留账号、会话、执行组合及用户修改；失败保留当前安装，不替换运行中的 profile。
