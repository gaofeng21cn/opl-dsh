官方 DeepSeek Harness：`{{OFFICIAL_VERSION}}` · OPL 增强：`{{VERSION}}`

本版发布主线新增的上下文预算、Auto Review 工具审批和 Todo 状态界面，并完善停止后编辑与协作反馈。官方桌面版本按发布时两个平台的实际 feed 配对；开发 API 依赖继续使用 `0.2.1-alpha.2`。

### 变更

- 新增上下文预算观测，默认关闭；开启后只显示可读取的预算与用量，来源和估算说明放在悬停提示中，不自动调整参数或压缩策略。
- 新增 Auto Review 工具审批，默认关闭；DSH 与 ZCode 可使用专用 `codex-auto-review` 或显式指定的独立审查模型，Codex 与 Claude 使用各自官方审核接口。缺失路线、审查失败或结果无法保存时不放行工具。
- 新增 Todo 状态面板，读取官方会话记录；会话停止后，未完成项目静态显示，父会话与子会话活动分别展示，不推测或自动更改完成状态。
- 完善停止后编辑的分支导航、原文草稿和界面收起行为；新建会话不复用尚未发送的编辑分支，原分支与草稿保留。
- 改善协作任务结束反馈、外部会话审核绑定与恢复；隐藏对话两侧空白区域的隐形宽度拖动区。

- Host/Client 类型检查、RPC、模块边界、格式、构建与自动测试：通过
- macOS arm64 与 Windows x64 未修改官方桌面隔离验收：通过

### 已知限制

- 官方桌面候选阶段以实际版本为准；开发 API cohort 与桌面 feed 分别记录，不把 `0.2.0-rc.2` 桌面称为 `0.2.1-alpha.2`。
- 隔离验收的本地模型 fixture 证明协议、工具和持久化链路，不代表真实 Gateway、外部模型质量或全部 Harness 组合已验收。
- Windows 受限 token 下的 Git Bash 外部程序仍有限制；已验证的真实 Git Bash 工具路径使用显式授权的 `danger-full-access`，不自动执行 ACL 修复。
- 停止后编辑目前面向原生 DSH 与公告会话历史扩展的 MiniMax；带附件消息不提供回填，已修改的磁盘文件保留。
- 直接打开官方桌面不会启动外部 OPL 更新器；OPL 维护入口或已启用自动启动的 Codex Skill 执行增强包更新，官方桌面继续由 DeepSeek 原生机制升级。

### 升级

退出 DeepSeek Harness 后运行最新安装器，或使用 OPL 维护启动入口。安装器和更新器校验联合清单与资产摘要；更新失败保留当前安装，不替换运行中的 profile。
