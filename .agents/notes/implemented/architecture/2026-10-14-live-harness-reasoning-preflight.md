# Live external Harness reasoning options

The model catalogue describes the native DSH effort vocabulary, while an external CLI owns its own advertised configuration. The model picker reads live ACP reasoning options before showing controls for CLI-owned efforts. An isolated, permission-matched ACP process reads the selected model with no prompt, no MCP tools, no task registration and no durable Suite session record. The process closes after the read; concurrent reads of the same Session and combination share one probe, and Host disposal drains pending probes. Codex and Claude retain their model declarations. Kilo and OpenCode have no selectable effort interface. MiniMax M3's on/off choices are derived from advertised model variants because its protocol has no separate thinking option. Unknown or failed reads hide the control and offer a retry. Closing and reopening the menu refreshes using the current permission; late reads cannot overwrite another Session or combination.
