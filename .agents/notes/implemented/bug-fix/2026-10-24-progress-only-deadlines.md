# 等待保护只限制无进展时间

Status: implemented

## Problem

单轮总时长计时器会取消仍在输出或执行工具的正常长任务，与等待保护防止无进展空转的目的不符。

## Decision

移除 totalMs 的设置、公开类型和运行计时器。只在首次进展等待或连续无进展超过配置时停止本轮。工具执行与人工等待暂停无进展计时，持续进展没有累计时长上限。旧配置的额外 totalMs 字段可以读取，但不进入运行限制快照，也不影响截止判断。

## Verification

虚拟时钟覆盖持续进展超过 90 分钟、工具执行一天、人工与工具等待交错，以及恢复后的无进展终止。原生 Agent 与外部 Harness 测试保留失败、取消、排队和审批行为检查；旧 totalMs=1 的配置不会触发终止。
