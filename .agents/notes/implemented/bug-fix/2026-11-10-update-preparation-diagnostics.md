# 更新准备与诊断

协议 1 的发布包可以不含本地辅助文件 `ofm-upgrade.cjs` 和 `update-errors.mjs`；安装器只对稳定安装入口声明必需项，同时验证清单列出的全部文件和拒绝未列出的文件。下载完成后的 ZIP、清单和协议验证失败携带 `verify/integrity`，避免归入下载阶段的未知错误。

更新检查和资产下载复用同一网络访问路径；更新准备失败记录固定阶段、原因及可选 HTTP 状态或系统错误码，不持久化响应正文、凭据或完整 URL。重试开始时清除上次失败，保留已验证版本和原安装。侧边栏更新入口通过现有通用设置导航定位更新区域，共享偏好行样式保持与官方设置一致。
