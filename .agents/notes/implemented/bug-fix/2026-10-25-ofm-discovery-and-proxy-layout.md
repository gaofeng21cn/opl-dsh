# OFM discovery and proxy option layout

The execution catalog projects the live OFM roster into a settings-only discovery list. Each entry is classified from the maintained official pairing table, the automatic adapter policy, registered adapters, and explicit exclusions. Unknown OFM models never become enabled combinations or trigger model requests. A generic DSH adapter is reported as manual-only rather than as an automatic adaptation.

Harness proxy choices use a left-aligned vertical radio list. Each option keeps its label and control on one baseline, and the custom endpoint field follows the selected option without an extra distribution gap.
