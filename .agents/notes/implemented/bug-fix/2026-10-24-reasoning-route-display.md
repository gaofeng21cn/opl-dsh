# 推理档位的执行组合准入

Status: implemented

## Problem

当前模型无法匹配已启用组合时，模型选择器曾把未确认的执行路线当作原生 DSH，显示供应商目录或旧会话记录中的通用推理档位。已停用或从目录移除的外部组合会因此出现未被该 CLI 广告的选项。

## Decision

仅已匹配的原生 DSH 组合使用供应商推理能力；外部组合继续使用当前 Harness 的预检结果。未确认组合、缺少能力或旧档位不在可选值中时，不显示推理选项或已选档位。组合与档位的持久记录不因界面隐藏而改写。

## Verification

组件测试覆盖组合缺失、组合停用、目录读取中、过期档位和 CLI 预检失败，并保留原生及外部有效档位的选择回归检查。
