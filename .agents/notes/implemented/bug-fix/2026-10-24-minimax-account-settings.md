# MiniMax 官方账号设置入口

Status: implemented

## User task and placement

用户在模型供应商页面查看 MiniMax 中国大陆和国际版的登录状态、网页登录、退出或取消授权。复用官方 settings.models.footer 插槽；程序路径留在执行引擎，不新增设置导航或凭据库。

## Ownership

mcode 负责认证、网页授权、凭据保存和刷新。OPL 只读取 auth-state.json 的状态白名单，不读取 auth.json，不返回授权码或令牌。凭据文件在退出后仍可存在，不能用于判断已登录。账号元数据描述本机状态，不保证联网认证或额度可用。地区仅 cn/global；未知命名空间不猜测其他目录。

登录与退出持有运行时维护门禁，取消不排队等待该门禁。取消发生于启动前时阻止后续进程创建；进程启动后仅停止本服务拥有的进程。停止失败保留所有权并报错，真实 close 后才释放。取消和超时后重读状态，处理授权恰好完成的竞态。网页登录不提供浏览器关闭通知；手动取消与十分钟授权上限负责结束等待。

## Verification

Host 聚焦测试覆盖地区状态、官方命令参数、取消和超时、进程停止失败以及启动前取消。Client 组件测试覆盖地区切换、登录退出、取消和请求晚到。真实安装与界面验收另记本轮交付报告，不通过测试注销用户账号。

授权重试使用独立 mcode 候选的可选 stdin 取消协议。官方核心负责按租约身份清理，OPL 不写账号元数据；授权租约与服务端有效期对齐。固定 stdout 控制行只包含版本标记和秒数，页面不复制授权码或 URL。独立目录的真实 CN 连续申请/取消验证了新授权码、状态 anonymous 和租约清除。
