---
title: 模型菜单与发送共享组合选择
kind: feature
status: implemented
---

Host 对新建、恢复和发送采用相同优先级：明确绑定、旧记录的唯一同路线替代、唯一默认项、唯一启用项。默认项包含原生 DSH。歧义或停用阻止发送，未登记组合的原生模型仍使用原生路径。首次请求将有效选择写入会话绑定，后续默认设置变化不隐式切换 Harness。Client 只显示 Host 返回的精确组合，不通过同模型列表猜测；外部模型投影变化触发一次 Host 刷新并隔离晚到响应。切换时按目标组合校验推理能力，CLI 档位由 Host 回读并标注来源，不由原生 provider 自动档位覆盖。
