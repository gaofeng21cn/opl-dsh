# OFM 委派失败诊断

原生 DSH 委派将官方等待结果的失败代码映射为固定诊断，未知代码仍记为失败，不把上游错误正文写入组合回执。Muse 的官方失败终态保留为失败；明确的 OpenCode 免费客户端限制使用专用类别，其他失败使用通用渠道类别。正文存在不覆盖失败终态，不自动重试或改路由。

Codex、ZCode 和 ACP 错误仅投影有限类别、有效 HTTP 错误状态、RPC 错误码及结束状态。原始消息和响应正文不进入持久诊断；没有结构化 HTTP 状态时不从消息猜测，RPC 代码不作为 HTTP 状态。未知原因不统一归为 CLI 安装或登录故障。

测试覆盖固定原生错误类别、未知代码不回显，以及 Muse 已有正文后收到客户端限制仍拒绝本轮并隐藏原始原因。真实全组合测试记录在本机 ofm-retest 报告中，联网可用性与固定诊断测试分别记录。
