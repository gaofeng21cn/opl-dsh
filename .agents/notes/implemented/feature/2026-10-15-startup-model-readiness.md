# 会话恢复与模型目录就绪

官方 ConversationRoot 在 Session 恢复前渲染工作区锁定输入框。OPL 的 composer 装饰器在 Session、input、keyboard、inputActions 齐备前显示本地化恢复状态，随后仍使用官方 InputBar。不能只取消 disabled：没有输入绑定时看似可编辑的控件不能发送消息，也不能在这一帧新建 Session 抢占已保存会话的恢复。

Harness 记录中的 nativeSessionId 表示官方持久 Session 已建立。启动仅迁移尚无此映射的记录；既有会话在续作时核对并恢复，模型目录读取不依赖任务历史恢复。模型选择只等待其自身保存的绑定，Client 独立发布当前选择与组合可用性，加载中的目录不显示为空目录。

回归覆盖已迁移的批量历史不重新打开、原历史首次迁移与模型选择保留、目录检查未结束时当前模型仍显示，以及输入绑定通知前后的官方组件切换。真实冷启动验收另外记录输入锁定与模型就绪时间；纯组件测试不能代替该证据。
