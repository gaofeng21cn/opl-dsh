---
title: OPL 登录密码由 Windows 凭据管理器保存
kind: feature
status: implemented
---

用户在原登录表单选择记住密码，默认关闭，认证成功后才保存。复用套件固定 keyring 凭据接口，条目为 `OPLDSH:Gateway:RememberedLogin`；Host 提供仅含邮箱的状态读取和显式使用保存密码的登录方法，Client 不接收保存的密码。用户取消勾选时清除该条目，退出账号不清除；保存失败返回已登录状态和独立提示。登录弹窗表单自身声明纵向 flex 布局，使覆盖共享样式后 gap 仍生效。

账号状态与密码保存状态并行读取；读取期间保留禁用的复选框位置，避免表单布局跳动。弹窗标题区同时使用共享 header 布局与窄屏覆盖类，防止仅有媒体查询的同名类覆盖基础 flex 间距。
